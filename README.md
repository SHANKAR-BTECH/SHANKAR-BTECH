## 🚀 What I'm Building

### 🌙 NightNote

An AI-powered productivity assistant designed to turn messy thoughts, tasks, deadlines, and personal context into **realistic and prioritized plans**.

The project is moving toward **local/on-device AI**, reducing dependency on external APIs.

**Focus:**  
`Local LLMs` `NLP` `Qwen` `PyTorch` `Android` `AI Planning`

---

### 🧠 NightNote Lite — Local LLM

My own lightweight model for the NightNote project, published on Hugging Face.

**Model:** `nightnote-lite-v2`  
**Format:** GGUF  
**Size:** ~135M parameters

Built with the goal of experimenting with **small, efficient models that can eventually run locally on resource-constrained devices.**

🤗 **[View NightNote Lite v2 →](https://huggingface.co/SHANKAR-017/nightnote-lite-v2)**
